# JAGANNATHCRAFATE

GitHub Pages-ready responsive website for devotional art/craft and a Student Corner.

### Included
- Floating Jagannath, Balabhadra and Subhadra header
- Vibrant category/shop sections
- WhatsApp + email ordering
- JITENDRA contact information
- Student Corner with class filters and keyword search
- Project ideas with materials, steps and presentation tips
- Photo Gallery with six categories
- Up to 10 photos per category
- One-click full-screen mobile-friendly gallery with next/previous controls

### GitHub Pages
1. Create a repository named `JAGANNATHCRAFATE`.
2. Upload `index.html` and this README.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save and open the generated Pages URL.

### Photo upload note
The in-page uploader stores selected photos in the browser's local storage. It does not automatically upload files to GitHub. For permanent public photos, put images into an `images/` folder in the repository and update the gallery HTML/JS to reference those files.
