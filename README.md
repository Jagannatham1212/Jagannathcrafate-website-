# JAGANNATHCRAFATE

A vibrant responsive art & craft website designed for GitHub Pages.

## Files
- `index.html` — complete website
- `README.md` — setup instructions

## Upload to GitHub
1. Create a new GitHub repository, for example `JAGANNATHCRAFATE`.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the live website address.

## Customise
Edit the product names, prices, descriptions and artwork inside `index.html`.
The contact information is already included.
