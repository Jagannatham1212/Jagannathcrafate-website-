# JAGANNATHCRAFATE Website

A responsive, animated static website designed for GitHub Pages.

## Files
- `index.html` — main website
- `style.css` — responsive design and animations
- `script.js` — menu, school class tabs and WhatsApp/email order form
- `logo.svg` — site favicon/logo
- `assets/` — uploaded craft photographs

## GitHub Pages
1. Create a GitHub repository.
2. Upload **all files and the `assets` folder** while keeping the folder structure.
3. Make sure `index.html` is in the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish.

## Important
The website intentionally does not display rates. Customers submit their requirements and contact the business for a custom quotation.

The order form is designed for static hosting: it prepares a WhatsApp message or an email. No server/database is required.
